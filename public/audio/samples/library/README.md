# Sample-Library

Lege hier deine gesamte Sample-Library ab. Unterordner bleiben erhalten und werden als Kategorien verwendet.

Beispiel:

```text
library/
  Drums/
    Kick/
      kick_analog_01.wav
  FX/
    riser_cinematic.mp3
  Vocals/
    vocal_chop_01.wav
```

Danach im Projektordner `npm run index:samples` ausführen. Dadurch wird die durchsuchbare Sample-Liste für die App erstellt.
